# 文档转照片插件更新日志

## v3.1.1 (2026-10-23)
- 修复大文档导入时界面卡死：分块处理改为「每块一次独立调度」，块与块之间 UI 线程可回到消息循环，输入、渲染与进度窗口动画不再被阻塞。
- 典型场景：80+ 页 PDF 导入时，旧版会在 UI 线程连续做几十次图片解码 + PNG 落盘 + 照片列表重建（数分钟无响应），现按块推进、界面保持可操作。
- 功能与参数无变化，转换结果与 3.1.0 一致。


## v3.1.0 (2026-08-15)
- 整份文档垂直拼接为一张长照片，支持本地转换缓存与同名修改检测。
- 新增图片拼接模块（ImageConcatenator），优化多页文档输出。
- 版本号统一为 3.1.0。

## v2.0.0 (2026-07-27)
- 使用 NPOI 与 PdfiumViewer 替代 Microsoft Office，无需安装 Office 即可转换 Word / Excel / PDF。
- 新增转换进度窗口，显示当前文件处理进度。
- 转换完成后自动将图片添加到照片列表，不再直接插入画布。
- 修复照片列表中多页文档生成图片时间戳冲突导致的误选问题。
- 支持通过设置项「文档转照片清晰度（DPI）」调整输出质量。
