# PPT视频增强插件更新日志

## v1.1.6 (2026-09-03)
- 修复：浮动栏处于鼠标状态时，鼠标移入/移出视频区域不再弹出"进入/离开鼠标模式"等多余提示。

## v1.1.5 (2026-08-18)
- 放映 PPT / WPS 时自动识别幻灯片中的视频控件区域。
- 鼠标移入视频区域即自动切换为鼠标/穿透模式，可直接操作播放器；移出后恢复批注模式。
- 浮动栏（float-bar）视觉保持不变，不受模式切换影响。
- 视频左下角新增透明的笔/播放切换按钮，点击可锁定批注模式或恢复自动切换。
- 同时支持微软 PowerPoint 与 WPS 演示。
- COM 探测在独立 STA 线程执行，界面轮询只读缓存快照，不影响书写流畅度。
