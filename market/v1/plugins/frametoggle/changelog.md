# 窗口边框开关插件更新日志

## v1.0.0 (2026-09-09)
- 首个版本。在插件工坊点击插件卡片上的「设置」图标，展开配置面板：一个总开关 + 每个窗口单独指定（跟随 / 隐藏 / 显示）。
- 通过 Win32 样式开关边框，不会触发窗口重建，无闪烁；仅作用于原本带边框的窗口，全屏画板与截图遮罩不受影响。
- 设置（MW_Settings）与插件工坊窗口已显式排除，避免把自己的设置面板也隐藏掉。
- 隐藏边框后仍可用 Alt+Space 调出系统菜单（移动 / 大小 / 关闭）。
- 配置持久化到插件目录 frametoggle.json；禁用或卸载本插件后恢复所有窗口的原始边框。
- 需主程序 26.9.5 及以上。
